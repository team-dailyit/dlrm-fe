# 용어집

프로젝트의 도메인 용어를 정리하는 문서다.
같은 개념을 여러 이름으로 부르지 않기 위해, 새 개념이 생기면 바로 추가한다.

## 공통

| 용어 (한글) | 영문 명칭 | 정의                   | 비고                             |
| ----------- | --------- | ---------------------- | -------------------------------- |
| 회원(예시)  | `User`    | 서비스에 가입한 사용자 | `Member`, `Account` 등 혼용 금지 |
|             |           |                        |                                  |

## 서비스

| 용어 (한글) | 영문 명칭        | 정의                                                                             | 비고                                                           |
| ----------- | ---------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 기준점      | `ReferencePoint` | 거리 계산의 원점. 현재 위치(`currentLocation`) 또는 동네(`neighborhood`) 중 하나 | 좌표가 아닌 동네 코드·"현재 위치" 플래그만 sessionStorage 저장 |
| 반경        | `Radius`         | 기준점으로부터의 직선 거리. 300m · 500m · 1km 중 선택, 기본 500m                 | 단위는 미터(`300`, `500`, `1000`)                              |
