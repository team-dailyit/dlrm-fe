# 용어집

프로젝트의 도메인 용어를 정리하는 문서다.
같은 개념을 여러 이름으로 부르지 않기 위해, 새 개념이 생기면 바로 추가한다.

## 공통

| 용어 (한글) | 영문 명칭 | 정의                   | 비고                             |
| ----------- | --------- | ---------------------- | -------------------------------- |
| 회원(예시)  | `User`    | 서비스에 가입한 사용자 | `Member`, `Account` 등 혼용 금지 |
|             |           |                        |                                  |

## 서비스

| 용어 (한글)  | 영문 명칭        | 정의                                                                               | 비고                                                                                                                                      |
| ------------ | ---------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 기준점       | `ReferencePoint` | 거리 계산의 원점. 현재 위치(`currentLocation`) 또는 동네(`neighborhood`) 중 하나   | 좌표는 저장하지 않는다. 동네 코드·"현재 위치" 플래그를 sessionStorage에 저장하고, 동네 기준만 localStorage에도 남겨 다음 방문 때 복원한다 |
| 반경         | `Radius`         | 기준점으로부터의 직선 거리. 300m · 500m · 1km · 2km 중 선택, 기본 500m             | 단위는 미터(`300`, `500`, `1000`, `2000`)                                                                                                 |
| 동네 코드    | `neighborhoodId` | 동네를 구분하는 식별자. 서버가 주는 정수 id (예: `1000000000001`)                  | API 응답의 `id`                                                                                                                           |
| 동네         | `Neighborhood`   | 서비스가 장소를 추천하는 지역 단위. 동네 코드·이름·대표 좌표·열린 장소 수를 가진다 | 목록은 `GET /neighborhoods` 로 받는다. 이름은 그 동네 지하철역 이름(API의 `station_name`)                                                 |
| 대표 좌표    | `coordinates`    | 동네를 기준점으로 삼을 때 거리 계산에 쓰는 좌표. 그 동네 지하철역의 좌표다         | `Neighborhood.coordinates`                                                                                                                |
| 열린 장소 수 | `openPlaceCount` | 서버 기준 지금 영업 중인 동네 안 장소 수                                           | API의 `open_place_count`. 시간에 따라 바뀌므로 오래 캐시하지 않는다                                                                       |
| 좌표         | `Coordinates`    | 위도·경도 쌍(`{ lat, lng }`)                                                       | 위치 좌표는 저장·로깅하지 않는다(GR-03)                                                                                                   |
