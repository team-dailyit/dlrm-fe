# 용어집

프로젝트의 도메인 용어를 정리하는 문서다.
같은 개념을 여러 이름으로 부르지 않기 위해, 새 개념이 생기면 바로 추가한다.

## 공통

| 용어 (한글) | 영문 명칭 | 정의                   | 비고                             |
| ----------- | --------- | ---------------------- | -------------------------------- |
| 회원(예시)  | `User`    | 서비스에 가입한 사용자 | `Member`, `Account` 등 혼용 금지 |
|             |           |                        |                                  |

## 서비스

| 용어 (한글) | 영문 명칭      | 정의                                                       | 비고                             |
| ----------- | -------------- | ---------------------------------------------------------- | -------------------------------- |
| 온보딩      | `Onboarding`   | 앱 진입 화면. 위치 허용 또는 동네 직접 고르기로 시작한다   | 경로 `/`                         |
| 동네        | `Neighborhood` | 서비스 지역 단위(성수·강남·안국·홍대). 대표 좌표는 역 좌표 | 동네 고르기 화면 `/neighborhood` |
| 지도 홈     | `MapHome`      | 지도와 장소 리스트를 보여주는 허브 화면                    | 경로 `/map`                      |
| 장소        | `Place`        | 지도에 노출되는 들를 만한 곳(전시·팝업·소품샵·서점)        | `Spot`, `Store` 등 혼용 금지     |
| 장소 상세   | `PlaceDetail`  | 지도 홈 위에 겹쳐 열리는 장소 정보 화면                    | 경로 `/map/place/:id`            |
