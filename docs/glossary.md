# 용어집

프로젝트의 도메인 용어와 화면 이름을 정리하는 문서다.
같은 개념을 여러 이름으로 부르지 않기 위해, 새 개념이 생기면 바로 추가한다.

- 도메인: 기획에서 다루는 개념. 코드의 타입·엔티티 이름의 기준이 된다.
- 화면: 라우트 단위 페이지. 영문 명칭은 `views`의 컴포넌트 이름과 맞춘다.

## 공통

| 용어 (한글) | 영문 명칭 | 정의                   | 비고                             |
| ----------- | --------- | ---------------------- | -------------------------------- |
| 회원(예시)  | `User`    | 서비스에 가입한 사용자 | `Member`, `Account` 등 혼용 금지 |
|             |           |                        |                                  |

## 서비스

### 도메인

| 용어 (한글)    | 영문 명칭                          | 정의                                                                                     | 비고                                                                                                                                                      |
| -------------- | ---------------------------------- | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 기준점         | `ReferencePoint`                   | 거리 계산의 원점. 현재 위치(`currentLocation`) 또는 동네(`neighborhood`) 중 하나         | 좌표는 저장하지 않는다. 동네 코드·"현재 위치" 플래그를 sessionStorage에 저장하고, 동네 기준만 localStorage에도 남겨 다음 방문 때 복원한다                 |
| 반경           | `Radius`                           | 장소를 찾는 범위(기준점으로부터의 직선 거리). 300m · 500m · 1km · 2km 중 선택, 기본 500m | 단위는 미터(`300`, `500`, `1000`, `2000`)                                                                                                                 |
| 동네 코드      | `neighborhoodId`                   | 동네를 구분하는 식별자. 서버가 주는 정수 id (예: `1000000000001`)                        | API 응답의 `id`                                                                                                                                           |
| 동네           | `Neighborhood`                     | 서비스가 장소를 추천하는 지역 단위. 동네 코드·이름·대표 좌표·열린 장소 수를 가진다       | 현재 서비스 동네는 성수·강남·안국·홍대 4곳. 목록은 `GET /neighborhoods` 로 받으며 API 응답이 기준이다. 이름은 그 동네 지하철역 이름(API의 `station_name`) |
| 대표 좌표      | `coordinates`                      | 동네를 기준점으로 삼을 때 거리 계산에 쓰는 좌표. 그 동네 지하철역의 좌표다               | `Neighborhood.coordinates`. 필드명 `coordinates` 는 대상마다 그 대상의 좌표(`Coordinates`)를 뜻한다 (장소 위치 `Place.coordinates` 등)                    |
| 열린 장소 수   | `openPlaceCount`                   | 서버 기준 지금 영업 중인 동네 안 장소 수                                                 | API의 `open_place_count`. 시간에 따라 바뀌므로 오래 캐시하지 않는다                                                                                       |
| 좌표           | `Coordinates`                      | 위도·경도 쌍(`{ lat, lng }`)                                                             | 위치 좌표는 저장·로깅하지 않는다(GR-03)                                                                                                                   |
| 장소           | `Place`                            | 지도에 노출되는 들를 만한 곳(전시·팝업·소품샵·서점)                                      | `Spot`, `Store` 등 혼용 금지                                                                                                                              |
| 장소 코드      | `placeId`                          | 장소를 구분하는 식별자. 서버가 주는 정수 id                                              | API 응답의 `id`                                                                                                                                           |
| 장소 검색 조건 | `PlaceSearch`                      | 주변 장소를 찾는 조건. 동네 코드 또는 좌표 중 하나와 반경으로 이루어진다                 | `GET /places` 의 `neighborhood_id` 또는 `lat`·`lng`, `radius` 로 바뀐다                                                                                   |
| 거리           | `distanceMeters`                   | 기준점에서 장소까지의 직선 거리(m). 서버가 계산한다                                      | API의 `distance_m`. 장소를 찾는 범위인 반경(`Radius`)과 구분한다                                                                                          |
| 영업 중        | `isOpenNow`                        | 서버 기준 지금 영업 중인지 여부                                                          | API의 `is_open_now`. 열린 장소 수의 "열린"과 같은 뜻                                                                                                      |
| 영업시간       | `operatingHours` / `OperatingHour` | 요일(`dayOfWeek`)별 영업 시작(`openTime`)·종료(`closeTime`) 시각과 휴무 여부             | API의 `operating_hours`. 요일 `DayOfWeek` 는 `MON`~`SUN`, 시각은 `"10:00"` 형식이고 휴무일이면 `null`                                                     |
| 휴무           | `isDayOff`                         | 그 요일에 영업하지 않는지 여부                                                           | API의 `is_day_off`                                                                                                                                        |
| 카테고리 코드  | `categoryId`                       | 장소의 카테고리를 구분하는 식별자                                                        | API의 `category_id`                                                                                                                                       |
| 썸네일         | `thumbnailUrl`                     | 장소의 대표 이미지 주소                                                                  | API의 `thumbnail_url`                                                                                                                                     |

### 화면

| 화면 (한글) | 영문 명칭          | 경로             | 설명                                                     |
| ----------- | ------------------ | ---------------- | -------------------------------------------------------- |
| 온보딩      | `OnboardingPage`   | `/`              | 앱 진입 화면. 위치 허용 또는 동네 직접 고르기로 시작한다 |
| 동네 고르기 | `NeighborhoodPage` | `/neighborhood`  | 동네를 직접 고르는 화면                                  |
| 지도 홈     | `MapHomePage`      | `/map`           | 지도와 장소 리스트를 보여주는 허브 화면                  |
| 장소 상세   | `PlaceDetailPage`  | `/map/place/:id` | 지도 홈 위에 겹쳐 열리는 장소 정보 화면                  |
| 페이지 없음 | `NotFoundPage`     | `*`              | 정의되지 않은 경로. 지도 홈으로 이동하는 링크를 보여준다 |
